# 中考英语备考学习台

按已确认的设计稿实现，边界为设计稿中的六个功能区与交互约定，不新增模块、不引入账号体系与云后端。

- 适用：浙江杭州 2027 届九年级学生，人教版（2024 修订版）九上，120 分制下 60–70 分（得分率 50%–58%）
- 基准日：2026-11-12；排布自 2026-11-16（周一）起共 31 周
- 运行：零依赖，直接双击 `index.html`；或在目录内执行 `python -m http.server 8000` 后访问 `http://localhost:8000`
- 数据：进度、错词本、分项得分、配比与公告保存在本机浏览器（localStorage），不上传

## 一、项目结构

| 文件 | 职责 | 对应设计稿 |
|---|---|---|
| `index.html` | 应用骨架：顶部工具条、六区导航、六个视图容器、打印容器 | 六个功能区 + A4 导出容器 |
| `styles.css` | 浅色主题、卡片/表格/题目等组件、`@media print` 打印样式 | 线上使用 + 可打印 |
| `data.js` | 全部内容数据：31 周、四阶段、九上 8 单元、8 专题、六板块清单、示意词表、12 道示意题与四栏解析、周测/模拟检测、工具、打印清单、边界 | 内容清单 |
| `app.js` | 状态与本地持久化、按周闸门、六区渲染、答题与解析揭示、错题回炉、打印生成、事件与启动 | 交互约定 |
| `COURSE-CONTENT.md` | 错因驱动课程包：三个完整单元、真实题面、答案与判定规则、即时反馈、复现安排、14 条可验收行为 | 具体练习课程内容 |
| `course.js` | 课程包结构化数据：3 单元 / 60 题（6 诊断 + 45 六技能 + 9 变式）、主题材料、词表、四栏解析、错因族、复现表、分级与完成条件 | 课程任务数据 |
| `course-app.js` | 错因任务流状态机：诊断闸门、一次一题、归因锁定、四栏解析、变式派发、D0/D2/D4/D7/D14 复现、教师复核、档案回翻、单元完成六条件、A4 导出 | 课程任务交互 |
| `README.md` | 项目结构、模块、交互成果、参考案例对照说明、运行与边界 | 交付说明 |

结构与逻辑分离：内容改动只动 `data.js`，不需要改渲染逻辑。

## 三、页面与交互成果（交互约定逐条对照）

| 设计稿交互约定 | 实现位置与行为 |
|---|---|
| 学生一进来只看当周，不暴露全量内容 | 阶段导航默认当周卡片；题目按 `level + openWeek` 过滤 |
| W01 只上线课本同步 + 词汇 + 听力；作文与模拟检测 W02 起开放 | `writingOpen()` / `mockOpen()` 闸门；W01 显示锁定提示；作文题 W02 起出现 |
| C 层练习 W17 才开放 | `levelCOpen()`；C 层题目需 `week >= 17` |
| 学生端先显示思路与依据，提交后再显示答案；教师端全量 | `revealAfterSubmit` + 角色判断；未提交显示提示条，不显示四栏解析 |
| 解析四栏：答案 / 依据类型 / 具体依据 / 易错提醒，禁止只给最终答案 | 每题 `.analysis-grid` 四格；阅读与完形题明确给出原文定位句 |
| 错题自动进错词本与同类题，按 2/4/7/14 天复现 | 答错客观题自动入队，生成复现周次；到期词高亮 |
| 打印件由线上模块生成，不单独维护纸质稿 | 7 个导出按钮从 `APP_DATA` 生成 `#print-root`，`@media print` 只输出打印容器 |
| 每日 10 词滚动听写条（7 新 3 旧） | 顶部「导出本周听写条」与打印清单 `dictation` |
| 周六周测：20 词 + 听力填空 + 作文提纲 + 任务型阅读 | 练测区周测卡片与打印清单 `weekly` |
| 阶段测只报四大板块分项得分率与错因归类，不排名 | 教师端录入 4 个板块得分率；阶段测卷打印含分项统计栏 |
| 每周先看分项得分率再调下周任务，不按总分调 | 教师维护区配比与公告位；页面无总分排名 |
| 教师端与学生端可见范围分开 | 顶部角色切换；教师维护区仅教师端可进入 |
| 题—知识点—错因三向关联 | 每题带 `knowledge` / `basisType` / `trap`；教师端按板块汇总错题数 |
| 作文只给批改量表、逐句旁批与升格示范，不代写范文、不整卷代做 | 工具区只列量表/清单/升格示范说明；解析讲义供教师讲评，学生端不整卷给答案 |

## 七、适用边界与限制

1. 需终端与网络；听力需耳机与安静环境，每周预留打印备份。
2. 纸笔默写、作文手写与卷面规范不能完全搬到线上，每日听写与作文初稿保留纸笔。
3. 作文自动评分不作依据，仍由教师按中考书面表达标准批改。
4. 教师需先录入内容；W01 基线、每周错词、2027 年官方通知均需人工更新。
5. 面向单个学生或普通班中等偏弱分段，不是全校统一备考系统。
6. 未引入账号体系与云后端（设计稿边界外），不做跨设备同步。
7. 不夸大应试承诺，不承诺分数。
